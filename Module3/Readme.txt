# **Модуль В.** Тестирование разработанной модели

**Краткое описание задания:** в рамках данного модуля необходимо покрыть разработанный программный продукт тестированием

**Файловая структура модуля:**

    -- saved_model\                         # папка с обученной нейросетью для суммаризации
    -- all_embs.pkl                         # датафрейм с эмбеддингами
    -- saved_model_cpu\                     # папка с обученной нейросетью для суммаризации
    -- app.py                               # интерфейс приложения
    -- backend.py                           # реализация
    -- doc2vec_e50_w2_mc1_dw0+dm1_.model    # файл с моделью сравнения 
    -- Readme.md                            # описательный файл в формате `.md`
    -- Readme.txt                           # описательный файл в формате `.txt`
    -- Report_M3.html                       # отчет о работе в формате `.html`
    -- Report_M3.ipynb                      # отчет о работе в формате `.ipynb`

Для работы с модулем, установите зависимости используя файл requirements.txt:

```bash
pip install -r requirements.txt
```
