# **Модуль Г.** Презентация решения

**Краткое описание задания:** в рамках данного модуля участникам необходимо подготовить презентацию своего решения, в которой необходимо отразить результаты тестирования, обоснование выбора алгоритмов, а также продемонстрировать работу решения.

**Файловая структура модуля:**

    -- presentation.odp                     # презентация в формате '.odp' 
    -- presentation.pptx                    # презентация в формате '.pptx' 
    -- Readme.md                            # описательный файл в формате `.md`
    -- Readme.txt                           # описательный файл в формате `.txt`
    -- Report_M3.html                       # отчет о работе в формате `.html`
    -- Report_M3.ipynb                      # отчет о работе в формате `.ipynb`

В этом модуле была разработана презентация покрывающая все аспекты работы. Презентация была продемонстрирована экспертам площадки
