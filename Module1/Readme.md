# **Модуль А:** Анализ и предобработка данных

**Краткое описание задания:** в рамках данного модуля участникам необходимо ознакомиться с представленным набором данных, проанализировать его структуру, содержимое и подготовить данные для обучения нейросети. 

**Файловая структура модуля:**

    -- Data\                    # папка с изначальными данными
    -- Module1\                 # папка модуля
        -- Dataset\                 # папка с сохраненными выборками 
            -- test.csv                 # `.csv` с тестовой выборкой
            -- train.csv                # `.csv` с тренировчной выборкой
            -- validation.csv           # `.csv` с валидационной выборкой

        -- final_dataframe.csv  # csv файл с не разделеным датасетом
        -- Readme.md            # описательный файл в формате `.md`
        -- Readme.txt           # описательный файл в формате `.txt`
        -- Report_M1.html       # отчет о работе в формате `.html`
        -- Report_M1.ipynb      # отчет о работе в формате `.ipynb`
        -- Testing1.ipynb       # тестовый вариант отчет в формате `.ipynb`
        -- requirements.txt     # файл с зависимостями в формате `.txt`


Для работы с модулем, установите зависимости используя файл requirements.txt:

```bash
pip install -r requirements.txt
```
