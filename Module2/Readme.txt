# **Модуль Б:** Разработка модели машинного обучения

**Краткое описание задания:** в рамках данного модуля необходимо разработать модель, которая будет решать поставленную задачу, а также интерфейсы взаимодействия с ней.

**Файловая структура модуля:**

    -- API                      # папка с реализованым API
    -- Dataset\                 # папка с сохраненными выборками 
        -- test.parquet                # `.parquet` с тестовой выборкой
        -- train.parquet               # `.parquet` с тренировчной выборкой
        -- validation.parquet          # `.parquet` с валидационной выборкой

    -- model-4-summary_cpu\                 # папка с обученной нейросетью для суммаризации
    -- saved_model\                         # папка с обученной нейросетью для суммаризации
    -- saved_model_cpu\                     # папка с обученной нейросетью для суммаризации
    -- all_embs.pkl                         # датафрейм с эмбеддингами
    -- data_summary.txt                     # файл со всеми суммаризациями текстов
    -- doc2vec_e50_w2_mc1_dw0+dm1_.model    # файл с моделью сравнения 
    -- Readme.md                            # описательный файл в формате `.md`
    -- Readme.txt                           # описательный файл в формате `.txt`
    -- Report_M2.html                       # отчет о работе в формате `.html`
    -- Report_M2.ipynb                      # отчет о работе в формате `.ipynb`

Для работы с модулем, установите зависимости используя файл requirements.txt:

```bash
pip install -r requirements.txt
```
